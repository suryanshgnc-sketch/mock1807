JEE MOCK CBT v2 — BEGINNER SETUP

WHAT YOU NEED
- Nothing for normal use.
- The simulator runs locally in your browser.
- Upload your question-paper PDF and start.

ANSWER KEY — EASIEST METHOD
1. Submit the test.
2. Choose “Official answer key — auto-evaluate”.
3. Paste the entire answer key into “Easiest: Paste the whole key”.
4. These formats are supported:
   A B C D A B ...
   1,2,3,4,1,...
   Q1-A Q2-C Q3-4 ...
5. Click “Apply key automatically”.
6. If anything is missing, edit that question directly in the grid.
7. Numerical questions accept numbers; MCQs accept A/B/C/D (or 1/2/3/4).

FULL ANALYSIS
After evaluation the report shows:
- Net marks and maximum marks
- Accuracy
- Attempted / unattempted
- Correct / incorrect / no-key questions
- Negative-mark loss
- Average time per attempted question
- Subject-wise correct, wrong, unattempted, marks, time and accuracy
- Slowest attempted questions
- Error/key-gap table
- Complete question-by-question review
- Printable report

OPTIONAL CLOUD BACKUP
You do NOT need an API/token for normal use.
Cloud sync is only for moving history between devices.

GITHUB TOKEN SETUP
1. Go to https://github.com and sign in.
2. Open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
3. Generate a new token.
4. Give it an expiry date.
5. Give only the “Gists” user permission with Read and write access.
6. Generate and copy the token.
7. In JEE Mock CBT, open Settings and paste it into the optional token field.
8. Click Backup.
9. On another device, enter the token and choose Restore.

SECURITY
Treat the token like a password. Do not share it, put it in screenshots, or publish it in a repository. Revoke it in GitHub if it leaks.

The cloud feature uses GitHub's Gist REST API. GitHub's current documentation says creating/updating a gist with a fine-grained token requires the Gists user permission with write access.
