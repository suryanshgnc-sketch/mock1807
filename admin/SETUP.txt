MOCK1807 ADMIN PORTAL — TEST/PDF STORAGE SETUP

This admin portal supports:
- Create tests with exact release date/time
- Upload question paper PDF
- Upload answer-key/solutions PDF
- Store both PDFs in private Supabase Storage
- Disable/enable tests
- Delete tests
- View students, attempts and scores

ONE-TIME SUPABASE SETUP
1. Supabase → Storage → New bucket
2. Bucket name: test-pdfs
3. Keep the bucket PRIVATE (do not make it public).
4. Supabase → SQL Editor → run the SQL below.

--- SQL ---

alter table public.tests add column if not exists enabled boolean not null default true;

insert into storage.buckets (id, name, public)
values ('test-pdfs', 'test-pdfs', false)
on conflict (id) do nothing;

drop policy if exists "Admins can upload test PDFs" on storage.objects;
create policy "Admins can upload test PDFs"
on storage.objects for insert to authenticated
with check (bucket_id = 'test-pdfs' and public.is_admin());

drop policy if exists "Admins can read test PDFs" on storage.objects;
create policy "Admins can read test PDFs"
on storage.objects for select to authenticated
using (bucket_id = 'test-pdfs' and public.is_admin());

drop policy if exists "Admins can update test PDFs" on storage.objects;
create policy "Admins can update test PDFs"
on storage.objects for update to authenticated
using (bucket_id = 'test-pdfs' and public.is_admin())
with check (bucket_id = 'test-pdfs' and public.is_admin());

drop policy if exists "Admins can delete test PDFs" on storage.objects;
create policy "Admins can delete test PDFs"
on storage.objects for delete to authenticated
using (bucket_id = 'test-pdfs' and public.is_admin());

--- END SQL ---

Do not make the bucket public. The answer key is stored in the private bucket and is not exposed by the student policies.
